# College Portal

A Java Full Stack Web Development project developed during my Summer Internship Program.

## 📌 Project Overview

**College Portal** is my first project in Full Stack Web Development using Java. The project was developed as part of my **Summer Internship Program in Java Full Stack Web Development** at **Precursor Info Solutions Pvt. Ltd.**

The application was developed using the **Java EE Platform** and **MySQL Database**, with a web-based frontend and backend.

## 🛠️ Technologies & Tools Used

### Frontend

* HTML
* CSS
* Bootstrap
* JavaScript

### Backend

* Java
* Java EE
* JSP (JavaServer Pages)
* Servlets
* JDBC

### Database

* MySQL WorkBench

### Development Tools

* Eclipse IDE
* Apache Tomcat

## 🎯 Project Objective

The **College Portal** was developed to gain practical experience in Java Full Stack Web Development and to understand the development of a database-driven web application using Java EE and MySQL.

## ✨ Key Learning Outcomes

* Developed a full-stack web application using Java
* Gained practical experience with Java EE
* Worked with JSP and Servlets for web application development
* Connected the application with MySQL using JDBC
* Used HTML, CSS and Bootstrap for the frontend
* Deployed and tested the application using Apache Tomcat
* Gained hands-on experience with Eclipse IDE
